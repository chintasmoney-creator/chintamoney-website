# ChintasMoney

Marketing site for **ChintasMoney** — *Less Chinta, More Life.*

Static site (HTML/CSS/JS), no build step. Custom domain: **chintasmoney.com**.

## Files
- `index.html` — the landing page
- `styles.css` — styles
- `script.js` — mobile nav, form validation, footer year
- `assets/logo.png` — brand logo (add this file)
- `CNAME` — custom domain for GitHub Pages

## Run locally
Open `index.html` in a browser, or:
```
python3 -m http.server 8000
```
then visit http://localhost:8000
